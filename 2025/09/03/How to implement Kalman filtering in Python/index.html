How to Quickly Implement Kalman Filtering in Python

Posted on 2025-09-03 Edited on 2025-09-23 Views: Word count in article: 719 Reading time ≈ 3 mins.

The Kalman Filter can estimate the state of a dynamic system from a series of noisy measurements. We can quickly implement the Kalman filter and smoothing algorithm in Python using the pykalman library.

Basic Formula

Predict step

  • Predict state vector XkX_kXk​:

Xk=FXk−1+Buk−1X_k=FX_{k-1}+Bu_{k-1} Xk​=FXk−1​+Buk−1​

XkX_kXk​ is the actual state of the system at time kkk (such as speed, position). FFF is the state transition matrix. uuu the control vector. uk−1u_{k-1}uk−1​ represents the control input of the system at time k-1 (such as acceleration).

  • Predict state covariance matrix PPP:

Pk=FPk−1FT+QP_k=F P_{k-1}F^T+Q Pk​=FPk−1​FT+Q

QQQ is the process covariance matrix.

Update step

  • Calculate Kalman gain KKK:

S=HPkHT+RS = HP_{k}H^T + R S=HPk​HT+R

K=PkHTS−1K=P_{k}H^T S^{-1} K=Pk​HTS−1

KKK represents the Kalman gain. RRR is the measurement covariance matrix, which needs to be determined based on the accuracy of the sensor.

  • Update state vector XXX:

X=Xk+K(zk−HXk)X=X_k +K(z_k-HX_k) X=Xk​+K(zk​−HXk​)

HHH is the observation matrix. zkz_kzk​ is the observation vector obtained by the sensor at time kkk. zk−HXkz_k-HX_kzk​−HXk​ represents the difference between the observed vector zkz_kzk​ and the predicted state vector XkX_kXk​.

III is the identity matrix of the same dimension as the state vector XXX.
